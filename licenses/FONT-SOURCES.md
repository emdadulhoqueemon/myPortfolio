# Self-hosted font sources

- Monotes — downloaded from the user-provided Google Drive file. Used for the brand signature and display headings.
- Saprona — downloaded from the user-provided Google Drive file. Used for UI and body text.
- Kohinur Bangla — downloaded from the user-provided Google Drive file. Used for Bengali content.
- Aref Ruqaa — retained for Arabic script content. Source: https://github.com/aliftype/aref-ruqaa

The Google Drive-provided custom font files should be kept with their original license terms and attribution if the project is redistributed publicly.
